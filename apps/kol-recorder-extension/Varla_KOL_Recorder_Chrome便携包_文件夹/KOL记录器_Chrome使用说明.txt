Varla KOL 记录器 Chrome 使用说明

一、先说重点

普通 Chrome 不能直接把 zip 当插件导入。
正确方式是：解压整包，然后在 Chrome 里加载 chrome_kol_recorder_extension 这个文件夹。


二、压缩包里有什么

1. start_kol_recorder.bat
   双击启动本地后台。使用插件前必须先打开，黑色窗口不要关。

2. kol_recorder_server.py
   后台写表脚本。一般不用手动打开。

3. outputs\varla_kol_tracker.xlsx
   KOL 台账。插件记录的数据会写到这里。

4. chrome_kol_recorder_extension
   Chrome 插件文件夹。Chrome 要加载这个文件夹。

5. kol_recorder_extension.zip
   插件单独备份包。普通 Chrome 开发者模式一般不用它，除非先解压。


三、第一次在普通电脑 Chrome 使用

1. 安装 Python 3.10 或以上版本。
   下载地址：https://www.python.org/downloads/
   安装时勾选 Add Python to PATH。

2. 解压整个 Varla_KOL_Recorder_Chrome便携包.zip。
   可以放到任意位置，例如 D:\Varla_KOL_Recorder。

3. 双击 start_kol_recorder.bat。
   第一次运行会自动安装 openpyxl。
   看到下面这行就说明后台成功：
   KOL recorder running: http://127.0.0.1:8765

4. 打开 Chrome。
   地址栏输入：chrome://extensions

5. 打开右上角“开发者模式”。

6. 点击“加载已解压的扩展程序”。

7. 选择这个文件夹：
   chrome_kol_recorder_extension

8. 打开 TikTok 或 Instagram 的 KOL 主页。
   例如：https://www.tiktok.com/@example_creator

9. 点击 Chrome 右上角的“KOL记录器”插件。
   勾选“同时抓取页面可见数据”，再点“记录当前KOL”。

10. 数据会写入：
   outputs\varla_kol_tracker.xlsx


四、使用注意

1. 记录 KOL 时，不要同时打开 varla_kol_tracker.xlsx。
   如果 Excel 或飞书正在打开这个文件，后台可能无法保存。

2. 只能在 KOL 主页点插件。
   不要在搜索页、消息页、视频详情页、记录结果页点击。

3. 卖家精灵 / EchoTik 页面也可以用。
   页面上显示“美国”“16.3K 粉丝”这类信息时，插件会尽量读取 Country 和 Followers。

4. Followers / Avg Views / Best Video Views 会用 K/M 格式写入。
   例如 8.1K、202K、1.9M。

5. Notes 默认不写长串抓取数字。


五、常见问题

问题：双击 start_kol_recorder.bat 后提示 Python is not installed。
处理：安装 Python，并勾选 Add Python to PATH。

问题：提示 No module named openpyxl。
处理：bat 会自动安装。如果失败，手动打开 CMD 输入：
python -m pip install openpyxl

问题：插件按钮是灰色。
处理：确认你在 TikTok/Instagram 的 KOL 主页，不是在搜索页、消息页、视频页。

问题：插件提示后台未启动。
处理：先双击 start_kol_recorder.bat，并保持黑色窗口打开。

问题：提示 xlsx 被占用。
处理：关闭 Excel / 飞书里打开的 varla_kol_tracker.xlsx，再重新点插件记录。
